## ⚙️ 핵심 전략: Wokwi First Strategy

```
가상 검증 (Wokwi) → 실물 구현 (Hardware) → 수익 창출 (Profit) → (반복)
```

부품 수급 전 **Wokwi 시뮬레이터**를 활용해 소프트웨어와 센서 제어 로직을 **100% 사전 검증**합니다. 시행착오와 하드웨어 오작동 리스크를 원천 차단하는 것이 우리 팀의 핵심 개발 철학입니다.

### Project 1. 🌱 인터랙티브 스마트 플랜트 '반려식물 봇' (B2C)

기존 반려식물 IoT 제품(6~10만 원대)은 단순 앱 알림/LED 수준에 머물러 있습니다. StepUp은 **4만 원대**에 '음성 + 터치 + 표정'의 완벽한 감성 인터랙션을 제공하여 시장을 파괴합니다.

| 기능 | 구성 요소 | 설명 |
|------|-----------|------|
| 👀 Visual/Voice | 0.96" OLED & DFPlayer | 수분/일조량에 따른 픽셀 표정(^\*^, T_T, -\*-) 애니메이션과 "목말라요!" 음성 출력 |
| ✋ Touch | TTP223 정전식 터치 센서 | 화분을 쓰다듬으면 반응하는 스킨십 인터랙션 |
| 💧 Automation | 토양 습도 센서 & 5V 워터펌프(릴레이) | 수분 부족 지속 시 자동 급수 시스템 가동 |

**수익성 분석**

| 항목 | 금액 |
|------|------|
| 제작 원가 (BOM) | 18,500원 |
| 목표 판매가 (와디즈/텀블벅) | 45,000원 |
| 개당 순이익 | **26,500원** |
| 예상 마진율 | **58.8%** |

### Project 2. 🎰 스마트 영수증 룰렛 게임기 (B2B)

기존 이벤트 업체의 대형 에어볼(회당 40~60만 원) 대비 **탁상형으로 공간 제약이 없으며**, 즉시 쿠폰 출력으로 방문객 참여율을 200% 증대시킵니다.

| 단계 | 구성 요소 | 설명 |
|------|-----------|------|
| 🔴 Input | 대형 아케이드 푸시 버튼 | 직관적인 방문객 참여 유도 |
| ✨ Visual/Audio | 서보모터 + WS2812B RGB LED 링 + 피에조 부저 | 화려한 감속 조명과 팡파르 사운드로 룰렛 연출 |
| 🧾 Output | 58mm 서멀 영수증 프린터 모듈 | 게임 결과에 따른 '5% 할인 쿠폰', '오늘의 운세' 즉시 현장 출력 |

**수익성 분석 (3일 단기 렌탈 기준)**

| 항목 | 금액 |
|------|------|
| 제작 원가 (BOM) | 42,000원 |
| 목표 대여가 | 150,000원 |
| 예상 마진율 (1회 대여) | **72.0%** |
| 2회 대여 이후 | 소모품(영수증 용지 1,000원) 제외 전액 순이익 전환 |

### Project 3. 🏓 2인용 레트로 초음파 '스마트 핑퐁' (B2C)

기존 코딩 키트(3~5만 원대)는 단순 LED 점등 위주의 지루한 예제에 머물러 있습니다. StepUp 제품은 **'2인 대전 비접촉 게임'**이라는 확실한 재미 요소로 교육 시장 대량 납품에 최적화되어 있습니다.

| 기능 | 구성 요소 | 설명 |
|------|-----------|------|
| 🎮 Control | 2x HC-SR04 초음파 센서 | 화면 터치 없이 손의 높낮이만으로 패들을 제어하는 비접촉 조작 |
| ⚡ Action | 2x TTP223 터치 센서 | '피버 모드' 강타 스매시 기술 탑재 |
| 📺 Display | 16x2 I2C LCD | 레트로 아케이드 감성의 공 반사 및 점수 물리 엔진 |

**수익성 분석**

| 항목 | 금액 |
|------|------|
| 제작 원가 (BOM) | 11,500원 |
| 목표 판매가 (스마트스토어/교육용) | 29,000원 |
| 개당 순이익 | **17,500원** |
| 예상 마진율 | **60.3%** |

## 🗓️ Unified 4-Week Execution Roadmap

```mermaid
graph LR
    A[1주차: 가상 검증] --> B[2주차: 회로 통합]
    B --> C[3주차: 기계 결합]
    C --> D[4주차: 최종 런칭]
```

| 주차 | 내용 |
|------|------|
| **1주차: 가상 검증** | Wokwi 100% 로직 완성(물리 엔진, 난수 확률, 그래픽) 및 BOM 부품 발주 |
| **2주차: 회로 통합** | 실물 배선, 센서 임계값 및 반응 속도 튜닝, 시리얼 통신 테스트 |
| **3주차: 기계 결합** | 화분, 아케이드, 미니 조종대 케이스 제작 및 모터/프린터 물리적 매립 |
| **4주차: 최종 런칭** | 오작동 디버깅, B2B 제안서 발송, 와디즈 페이지 오픈 및 실전 시연 |
