# 이전 발표 자료 개선하기

# 반려식물 봇 → PlantMate Pro : SCAMPER 재설계

무제한 예산·개발 시나리오를 가정하고, 아두이노 기반 반려식물 봇(Project 1)을 SCAMPER 기법으로 재설계한 내용입니다.

## 왜 반려식물 봇을 선택했는가

- **가장 확장성 높은 카테고리**: 감성 테크(Emotional Tech) B2C는 구독·커뮤니티 모델로 확장하기 가장 유리함
- **시장 상한선이 가장 넓음**: 영수증 룰렛(B2B 팝업 마케팅 니치), 핑퐁(에듀테크 니치) 대비 대중 소비재로서 잠재 시장이 큼
- **팀 비전과의 정합성**: "생태계 확장, 초연결 B2B"라는 StepUp의 스케일업 비전과 가장 잘 부합

---

## S · 대체 (Substitute)

- 아두이노 우노 → **Arduino Nano ESP32** (정품 Arduino 브랜드 보드, ESP32-S3 기반 WiFi/BLE + 카메라 인터페이스)
- 0.96" 흑백 OLED → **1.5" 컬러 IPS 터치 디스플레이**로 표정 애니메이션 고도화
- 단일 정전식 터치 센서 → **정전용량 센서 배열**로 쓰다듬는 강도·속도까지 인식

## C · 결합 (Combine)

- 카메라 + AI(온디바이스/클라우드 비전 모델)로 **병충해·잎 상태 자동 진단**
- 토양수분 + 공기질 + 조도 센서를 통합해 **종합 식물 건강 리포트** 생성
- 앱 연동으로 "내 식물 자랑" **커뮤니티 기능** 결합

## A · 응용 (Adapt)

- 스마트 스피커의 **음성비서 UX**를 차용해 자연어로 "얘 요즘 왜 이래?" 질문 가능
- 반려동물 헬스 트래커의 **케어 스코어 시스템**을 식물에 적용

## M · 확대 (Magnify)

- 세라믹·원목 등 **프리미엄 마감재**로 인테리어 오브제급 디자인
- **완전 무선 + 태양광 자가발전**으로 전원 걱정 없는 화분
- 화분 **사이즈·디자인 라인업 다양화** (미니~대형)

## P · 다른 용도로 (Put to another use)

- **시니어 정서케어**: 요양원·시니어센터용 원예치료·인지자극 콘텐츠 기기로 확장
- **웰니스 오피스**: 사무실 웰니스 오브제, 병원 대기실 정서 케어 기기

## E · 제거 (Eliminate)

- 물리 버튼 완전 제거 → **터치 + 음성 전용 인터페이스**
- 유선 전원 제거 → **완전 무선/태양광화**

## R · 반전 (Reverse)

- 기존엔 "사람이 식물을 돌보는" 구조 → **식물이 사람의 물 섭취량·활동량을 체크해 알림을 주는** 컨셉으로 전환
- "식물이 날 케어하는 반려식물"이라는 발상의 전환

## 비즈니스 모델 전환

| 구분 | Before (일회성 판매) | After (하드웨어 + 구독) |
|---|---|---|
| 가격 | 45,000원 | 129,000원 + 월 구독 4,900원 |
| 마진율 | 58.8% | 하드웨어 원가 상승분을 구독 매출로 상쇄 |
| 매출 구조 | 판매 1회로 종료 | 하드웨어 + 반복 구독 매출 |
| 고객 관계 | 구매 이후 접점 없음 | 앱을 통한 지속적 접점 확보 |
| 핵심 가치 | 감성 인터랙션 하드웨어 | 락인 구조로 LTV(고객생애가치) 극대화 |

**결론**: PlantMate Pro는 감성 테크 하드웨어에 AI 진단과 구독형 서비스를 결합해, 일회성 판매를 넘어선 반복 수익 구조를 만드는 것을 목표로 합니다.
